# Bake compact diagnosis previews into inst/previews

Bake compact diagnosis previews into inst/previews

## Usage

``` r
bake_previews(designs = NULL, sims = 100)
```

## Arguments

- designs:

  Ids/aliases, or `NULL` for shiny-included designs.

- sims:

  Number of simulations (package default is 100).

## Value

Invisibly, paths written.
